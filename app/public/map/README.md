Map assets for /producers/map.
- fonts/: Noto Sans glyphs (SIL Open Font License, see fonts/OFL.txt) from github.com/protomaps/basemaps-assets.
  Only Latin ranges are kept; the Worker returns an empty glyph file for any other range.
- sprites/: map icons from github.com/protomaps/basemaps-assets (derived from MIT-licensed tangrams/icons).
- vendor/: MapLibre GL (BSD-3), PMTiles (BSD-3) and Protomaps basemaps (BSD-3), copied from node_modules at build time.
Map data: © OpenStreetMap contributors (ODbL), via Protomaps builds. Stored in R2 bucket rp-tiles as uk.pmtiles.
